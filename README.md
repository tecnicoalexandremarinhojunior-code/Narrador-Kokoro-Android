# Narrador Kokoro Android

Narração por IA (Kokoro-82M via Sherpa-ONNX) rodando offline no Android. Vozes pt-BR: Dora, Alex, Santa.
O APK é compilado pelo GitHub Actions (`.github/workflows/build-apk.yml`) e fica em Actions > execução > Artifacts.

Status (Etapa 2): editor, projetos, 3 vozes, velocidade, download do modelo, geração em blocos com retomada,
player, exportação WAV. Ainda não testado em aparelho. MP3 será implementado na Etapa 5.
